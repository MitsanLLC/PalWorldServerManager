# Pal Server Hub v0.9.0 Preview

Pal Server Hub is the first branded preview release of the Palworld dedicated-server management application developed by **Stancean**, a **Mitsan LLC** product.

## Branding

- Product: **Pal Server Hub**
- Product website: https://palworldserverhub.com
- Short domain: https://palserverhub.com
- Developer: **Stancean**
- Developer website: https://stancean.com
- Support development: https://ko-fi.com/mitsanllc
- Publisher: **Mitsan LLC**

Pal Server Hub is an independent community tool and is not affiliated with or endorsed by Pocketpair.

## Highlights

- Server process controls and attach-to-running support
- Settings editor
- Live server health and metrics
- Startup diagnostics
- Player administration
- Console commands
- Persistent logs
- Backups and retention
- Scheduler
- PAK mod management
- Crash recovery
- Discord notifications
- SteamCMD update-before-start
- Start with Windows
- First-run setup wizard
- Built-in Help & Guides
- Pal Server Hub branding, application icon, and installer identity
- Support Development link

## Release Status

v0.9.0 is a preview release. Test it on a non-critical server before wider distribution and back up important worlds before testing restore, mod, or recovery workflows.
